# amazon-powerbi-dashboard
Interactive Amazon Product and Review Analytics Dashboard built using Power BI

->Project Overview

An interactive Power BI dashboard for analyzing Amazon products,
pricing, discounts, ratings, and customer reviews.

->Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Kaggle Dataset

->Dashboard Pages

1. Overview
Provides a high-level summary of products, reviews, ratings,
discounts, and product categories.

2. Product & Pricing
Analyzes product prices, discount amounts, discount percentages,
and highly reviewed products.

3. Reviews & Customers
Analyzes customer reviews, users, ratings, and review activity.

->Data Preparation

Data was cleaned and transformed using Power Query.
Separate Products, Reviews, and Users tables were created
for better data modeling.

->Key Features

- Interactive category filtering
- KPI cards
- Product analysis
- Pricing analysis
- Discount analysis
- Rating analysis
- Review analysis
- Interactive charts and slicers
